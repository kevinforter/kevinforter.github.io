Privacy Policy

Last updated: October 2026

Scope

prefect-uploader is a private automation tool used solely by its owner, Kevin Forter. It is not offered to other users.

Google user data accessed

The application requests only the https://www.googleapis.com/auth/drive.file scope. This allows it to create and manage files it has created itself in the owner's Google Drive. It cannot see or access any other files.

How data is used

Files produced by the owner's data pipelines are uploaded to a Google Drive folder owned by the owner. No Google user data is sold, shared with third parties, used for advertising, or used to train machine learning models.

Storage and security

OAuth tokens are stored as encrypted secrets in the owner's workflow orchestration account and are never published. Access can be revoked at any time at myaccount.google.com/permissions.

Compliance

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: contact the owner via the support e-mail listed on the Google consent screen.
